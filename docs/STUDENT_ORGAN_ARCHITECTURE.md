# Student Organ Architecture

## Organ model

StarLiz Academy learning intelligence follows organ boundaries:

- Brain: canonical read intelligence and classification.
- Blood: transport contracts for push and pull flows.
- Stomach: evidence digestion into normalized signals.
- Anus: lifecycle retention/archive/disposal governance.

## Required guardrail statement

Respect StarLiz organ boundaries: Brain thinks, Blood transports, Stomach digests, Anus manages lifecycle.

## End-to-end information flow

1. Learning events are emitted from product and learning workflows.
2. Blood routes event envelopes through defined destinations.
3. Stomach digests raw evidence into deterministic signals.
4. Brain composes canonical intelligence views and recommendations from digested evidence plus historical records.
5. Blood serves push/pull distribution for approved consumers.
6. Anus assigns lifecycle policy for retention, archive eligibility, and controlled disposal decisions.

## Hard constraints

- Brain is read-focused and must not become a write workflow orchestrator.
- Blood is transport-only and must not compute intelligence.
- Stomach is digestion-only and must not write to database.
- Anus must not execute automatic purge in this phase.

## Governance expectations

- Every organ keeps clean exports and typed contracts.
- New features should map explicitly to one organ concern.
- Cross-organ integration must be validated by guardrail tests.
