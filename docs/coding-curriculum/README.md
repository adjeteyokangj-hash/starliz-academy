# StarLiz Coding Curriculum — approval package

Prepared 2 November 2026. **Approved by the user as the implementation baseline on 2 November 2026. Implementation is in progress; approval is not a claim of delivered curriculum coverage.**

The recommendation is **264 core lessons**, supported by **132 consolidation sessions**, across the existing five pathways. Eleven year courses contain 44 modules, each ending in a meaningful portfolio project. This replaces the 66-lesson proposal as the recommended planning baseline, subject to approval; the original document and application catalogue remain unchanged.

Read the package in this order:

1. [Coverage report](COVERAGE_REPORT.md): findings, missing skills, progression, depth and recommendations.
2. [Curriculum design](CURRICULUM_DESIGN.md): identity, pathways, teaching, mastery, portfolios and age progression.
3. [Coverage matrix](COVERAGE_MATRIX.md): England statutory reference and StarLiz extension evidence.
4. [Lesson inventory](LESSON_INVENTORY.md): all 264 proposed lesson objectives, challenges, debugging tasks, independent variations and checks.
5. [Review of the original 66 lessons](ORIGINAL_66_REVIEW.md): every original lesson's disposition and new location.
6. [Implementation plan](IMPLEMENTATION_PLAN.md): dependencies, authoring, verification and approval gates.

The [planning JSON](curriculum-proposal.json) contains the complete structured inventory, explicit prerequisite references, seven-stage instruction designs, lesson mastery criteria, project milestones, alignment codes and existing runtime aliases. It is a review artifact outside application content, not a seed file or publication payload. [Integrity validation](PLANNING_VALIDATION.json) checks references and completeness of the proposal; it does not certify educational quality or working lesson engines.

The academic reference is the [Department for Education's computing programmes of study for England](https://www.gov.uk/government/publications/national-curriculum-in-england-computing-programmes-of-study/national-curriculum-in-england-computing-programmes-of-study). This package makes no curriculum-equivalence claim for the other UK nations and no GCSE examination-board or qualification claim.

The user's “Complete Coding Learning Implementation” instruction approves this design baseline and supersedes the earlier planning-only gate. The inventory and planning documents remain the approved specification; executable lesson packages and their verification records are separate. Commits, pushes and application deployment still require approval. Only reviewed additive migrations may be applied after target and history verification.

The [AI privacy operations note](AI_PRIVACY_OPERATIONS.md) records the unverified provider retention status and the resulting restrictions on personalised younger-learner tutoring and explanation review.

The [web workspace verification note](WEB_WORKSPACE_OPERATIONS.md) describes actual isolated HTML/CSS inspection, inert browser previews, original supplied media and the limits of each verification record.

The [private demonstration operations note](PRIVATE_DEMONSTRATION_OPERATIONS.md) describes source- and task-bound recordings, isolated decoding, encrypted storage, required configuration and the separate authenticated verification requirements.
