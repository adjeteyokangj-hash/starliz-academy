# DPIA Draft Checklist (UK Launch)

Status: Draft checklist for privacy/safeguarding/legal review.

## A. Processing Overview
- [ ] Describe processing activities involving child data.
- [ ] Map parent consent lifecycle and withdrawal handling.
- [ ] Confirm AI processing contexts and decision support boundaries.

## B. Necessity and Proportionality
- [ ] Confirm each child-data field has a clear educational purpose.
- [ ] Confirm data minimisation in profile and activity pipelines.
- [ ] Confirm retention windows are documented and justified.

## C. Risk Identification
- [ ] Unauthorised access to child records.
- [ ] Over-collection or excessive retention.
- [ ] Inadequate parent transparency for AI usage.
- [ ] Incomplete audit trail for sensitive actions.

## D. Mitigations and Controls
- [ ] Server-side consent checks before child learning endpoints.
- [ ] Role-based access guards for admin and school routes.
- [ ] Auditable export/deletion request workflow.
- [ ] Sensitive admin action audit logging.
- [ ] Monitoring and incident response controls.

## E. Residual Risk and Decisions
- [ ] Record residual risk after technical controls.
- [ ] Assign risk owner and review date.
- [ ] Determine whether consultation with ICO/legal advisor is required.

## F. Evidence Attachments
- [ ] Policy drafts: privacy, terms, cookie, safeguarding, retention.
- [ ] UK GDPR data map.
- [ ] Test evidence for consent and data-request controls.

## Manual Review Required
This checklist is not a completed DPIA. A qualified legal/privacy reviewer must complete and approve final DPIA documentation before production release.
